# Historical collector compatibility

This tree owns the remaining GateHouse #10 collector implementation tests.
`inventory.json` binds every original test/helper/fixture to GateHouse commit
`226b5b5` (the complete revision is in the inventory). The snapshot preserves
original paths and test bodies. Frozen Core Python modules are non-authoritative
reference inputs, not a release fallback. Current public plugins are separately
accepted against the released Core 0.4.9 by the existing plugin matrix.

`run.py` verifies the snapshot, enumerates every inherited unittest method, runs
all applicable original tests with zero skips, and compares the Core policy and
preset fixture with the original Angular/V8 producer. Positive/negative replay,
transport, parser, source maps, artifact and context checks retain their original
Linux scope. The textual MIR experiment uses the exact original Rust 1.97.1 and
LLVM tools; this does not certify the stable candidate or widen native platforms.

The eleven `StandaloneNativeTests` remain explicitly held because they require
the suspended assembled private Linux runtime. Their original bodies, helper
imports and build-input rejection tests remain here. Ordinary Core CI previously
skipped this entire opt-in class. No bundle is assembled, published or substituted
with the independent native product. The two ordinary build/layout tests run.
The held methods are reported individually and never counted as passing tests.

Core retains its generic TypeScript debt/ratchet, mixed Rust/TypeScript policy,
preset composition, frozen reference and protocol tests. The original nine
policy methods plus TypeScript preset method also run here only to prove the
fixed facts are equivalent. Per-method owner, scope, execution and hold reason
are recorded in the uploaded result; all imported file owners are in the inventory.

The required CI job has a 15-minute timeout and uploads one bounded JSON result
for seven days. It restores verified historical data from the existing immutable
source-data release (two archives, about 36 MB), executes one Linux replay and
native experiment, and does not repeat the four-platform plugin matrix in Core.
Roll back the Core handoff and restore local selection if parity is withdrawn;
original test bodies and immutable historical assets remain available.

Engineering Policy semantics are unchanged: Rust Core owns decisions,
requiredness, thresholds, baseline, lineage, debt and release eligibility.
